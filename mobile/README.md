# Everkin — React Native iOS App

Native iOS app for Everkin (FinanceGPT), built with React Native + Expo.

## Architecture

- **Frontend**: React Native (Expo SDK 52)
- **Data layer**: Embedded SQLite (expo-sqlite) — offline-first, no server required
- **AI**: Yolo-Auto OpenAI-compatible API (streaming chat)
- **Market data**: Yahoo Finance (no API key needed)
- **Auth**: Local (expo-secure-store for token persistence)
- **i18n**: 40 languages (11 built-in, rest via AI translation cache)
- **Cloud sync**: Optional — set `ATLAS_URL` in config to enable MongoDB Atlas sync

## Getting Started

### Prerequisites
- Node.js 18+
- Expo CLI (`npm install -g expo-cli`)
- Xcode 15+ (for iOS build)
- EAS CLI (`npm install -g eas-cli`)

### Install
```bash
cd mobile
npm install
```

### Run (development)
```bash
npx expo start
# Press 'i' to open in iOS Simulator
```

### Build for iOS (production)
```bash
eas build --platform ios
```

### Submit to App Store
```bash
eas submit --platform ios
```

## Data Layer

The app uses **embedded SQLite** (via expo-sqlite) — no backend server required.

Tables mirror the MongoDB collections from the Electron app:
- `users`, `conversations`, `messages`
- `investments`, `insurance`, `documents`
- `reminders`, `contacts`, `life_events`
- `gmail_messages`, `shares`, `translations`, `form_copies`

To switch to a **remote backend** (FastAPI), set `BACKEND_MODE: 'remote'` in `src/config.js`.

## AI Integration

Uses Yolo-Auto API (OpenAI-compatible):
- Streaming chat responses
- System prompt includes user profile, knowledge base, investment list
- Detects `[LANG_CHANGE:xx]`, `[INV_ADD:...]`, `[INV_EDIT:...]`, `[INV_DELETE:...]`, `[DOC_GEN:...]` markers

Set API key via `expo-secure-store` at runtime or in `src/config.js`.

## i18n

40 languages supported:
- 11 built-in translations (en, hi, bn, ta, te, mr, gu, kn, es, fr, de)
- AI-translated keys cached in SQLite for instant loading
- Language switcher in Profile screen

## Cloud Sync

Optional — set `ATLAS_URL` in `src/config.js` to enable MongoDB Atlas sync.
Sync engine is compatible with the Electron app's sync protocol.
